# Coordinator guide — opening interview access for a next rotation

When a participant holds a role, the portal **pauses their interview requests** so they
can't line up a second placement by accident. This applies to three statuses:

- **Placed** — accepted a role
- **On Program** — currently working the role
- **Complete** — finished the rotation

While paused, the participant sees **"Interview Unavailable"** on any job, and the
request button is disabled.

**Nothing re-opens automatically.** When a participant is eligible for a next
rotation, a coordinator opens their access by hand. (Some participants finish the
program but aren't eligible to travel again — so this is always a deliberate step.)

## How to open interview access

1. Sign in as **Admin** → **Participants**.
2. Find the participant and click **Edit**.
3. Under **Portal access**, tick **"Allow interview requests (override Placed / On Program / Complete)."**
4. Click **Save**.

The participant can now request interviews again — up to the normal **2 open
requests** at a time — **without changing their status**. They stay On Program (or
Complete) in your records.

A green **"Requests open (override)"** badge shows on their card so you can see at a
glance who has been opened.

## To pause them again

Edit the participant and **untick** the same box, then Save. Their requests pause
again immediately.

## Related controls (unchanged)

- **Block interview requests & reviews** — a hard block that stops requests *and*
  reviews regardless of status. Use for a problem account, not for rotation flow.
- **Suspend portal access entirely** — logs the participant out of their portal data
  (they see a restricted-access message).

## Status flow for reference

`Requested → Interviewing → Offered → Placed → On Program → Complete`
(Withdrawn is available at any point.)

Change a participant's status in **Admin → Applications** using the status buttons on
each application.
